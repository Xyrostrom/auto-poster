Privacy Policy

Last updated: 4 November 2026

Auto-poster is a personal tool used only by its owner, Shikhar Singh, to publish the owner's own videos.

What Google data it uses

  • Google Drive (read-only): it reads video files from one Drive folder chosen by the owner, so it can publish them.
  • YouTube (upload): it uploads those videos to the owner's own YouTube channel.

How the data is handled

  • Videos are downloaded temporarily while a post is made and then deleted.
  • Only a list of which files were already posted is kept, so the same video is not posted twice.
  • Google user data is not sold, shared with third parties, or used for advertising.
  • OAuth credentials are stored as encrypted GitHub Actions secrets and are never published.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
